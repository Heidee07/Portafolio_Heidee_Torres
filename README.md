## ✨ Features

- **Bilingual Interface (ES / EN):** Seamless language toggle allowing international and local recruiters to explore profile details in their preferred language.
- **Project Showcases & Live Access:** Detailed case studies including live application links, direct GitHub source code access, and pre-configured test credentials for instant evaluation.
- **Enterprise Impact Highlights:** Metrics-focused presentation of business results, such as automated XML invoice processing and operational efficiency improvements.
- **Responsive & Dark-Themed UI:** Clean, modern dark aesthetics with neon accents, optimized for smooth navigation across mobile, tablet, and desktop viewports.
- **Direct Contact & Resume Download:** Fast access to download an up-to-date CV and reach out via LinkedIn or email with zero friction.

---

## 🛠️ Built With

- **HTML5 & CSS3:** Semantic markup and custom styling (dark modern UI with glow accents).
- **JavaScript:** Dynamic bilingual state management (ES/EN switch), interactive navbar animations, and smooth scrolling.
- **Bootstrap 5:** Mobile-first layout structure and responsive grid system.
- **Hosting / Deployment:** Hosted and deployed on MonsterASP.NET.
